# Spotify Data Analysis & Visualization Project

## 📌 Project Overview
This project demonstrates an end-to-end data analytics workflow. It starts with raw data exploration and querying using **SQL** to extract key musical trends, followed by building an interactive visual dashboard in **Tableau** to present the insights professionally.

## 📊 Core Insights & Metrics Addressed
* **Total Track Volume:** Successfully quantified a core library of 76 unique tracks.
* **Genre Distribution:** Analyzed track representation across genres, tracking dominating trends like Acoustic and Afrobeat.
* **Artist Popularity Rankings:** Identified and isolated the Top 10 most popular artists based on their average song popularity scores rather than simple track counts.
* **Content Breakdown:** Visualized the precise split between explicit and non-explicit tracks (66 Clean vs. 10 Explicit).
* **Track Duration Analysis:** Calculated the average song length in milliseconds across different genres to discover formatting trends.

## 🛠️ Technologies Used
* **Backend Data Querying:** SQL (Aggregations, Filters, Grouping, Sorting)
* **Frontend Visualization:** Tableau Desktop (KPI cards, Horizontal Bar Charts, Pie Charts, Interactive Dashboard Action Filters)

## 📁 Repository Structure
* `spotify project.sql`: Contains the complete SQL code utilized to isolate, clean, and aggregate the raw track metrics.
* `spotify_data_analysis_project.twbx`: The fully compiled, packaged Tableau workbook displaying the interactive reporting dashboard layout.
